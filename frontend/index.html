The free server sleeps when idle, so the first request can take up to a minute.

CSV format

The first row is the header; column order doesn't matter.

  • skurequired · unique, ignores case
  • namerequired
  • descriptionoptional
  • priceoptional · number
  • activeoptional · true / false
  • Importing a SKU that already exists updates it; if a file repeats a SKU, the last row wins.
  • Invalid rows are skipped and counted, never silently dropped.
